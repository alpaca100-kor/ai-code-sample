------------------------------------------------

## 2. 프로그램 목적

연도(및 월)를 입력하면 해당 월 또는 해당 연도 전체의 달력을 보여주는 단순한 웹 달력 앱. 월별보기와 1년전체보기 두 가지 모드를 지원하고, 대한민국 공휴일 정보를 함께 표시한다.

------------------------------------------------

## 3. 주요 기능

필수 기능

① 연도/월 입력 시 해당 월의 달력 표시 (월별보기)
② 연도 입력 시 1월~12월이 끊김 없이 이어지는 연속된 주(週) 단위 형태의 1년 전체 달력 표시 (1년전체보기). **주의: 월 단위로 12개 블록을 나열하는 것이 아니라 '주' 단위 행이 연초부터 연말까지 끊김 없이 이어지는 구조이며, 총 행 수는 12행이 아니라 연도에 따라 약 52~54행임 — 정확한 구성 로직은 6번 항목 참고**
③ 이전달/다음달, 이전해/다음해 이동 버튼 및 오늘/올해로 즉시 이동하는 버튼
④ 오늘 날짜 강조(원형 표시), 토요일/일요일 날짜 색상 구분
⑤ 대한민국 공휴일 표시 — 날짜를 색상으로 구분하고, PC는 마우스를 올리면·터치스크린은 탭하면 툴팁으로 공휴일명을 표시

선택 기능

① 다크모드 — 시스템 설정 자동 감지 + 수동 전환 버튼, 선택값은 다음 방문 시에도 유지
② 1년전체보기에서 요일 헤더 행이 스크롤 시 상단에 고정(엑셀 틀고정과 동일한 방식)

------------------------------------------------

## 4. 사용자 작업 순서

1. HTML 파일을 브라우저로 열어 앱 실행
2. 상단 [월별보기] / [1년전체] 탭 중 원하는 보기 모드 선택
3. 연도(및 월)를 입력하거나 이전/다음 버튼으로 원하는 시점 탐색
4. 공휴일 날짜에 마우스를 올리거나 탭하여 공휴일명 확인
5. (선택) 우측 상단 버튼으로 다크모드 전환

------------------------------------------------

## 5. 화면 구성 (레이아웃)

상단
- 장식용 스프링 제본 표시(rings), [월별보기]/[1년전체] 탭, 다크모드 전환 버튼

중앙
- 월별보기 : 연도/월 큰 숫자 표시 + 연도 입력·월 선택·이전달·다음달·오늘 버튼 + 요일 헤더 + 7열 × N행 날짜 그리드
- 1년전체보기 : 연도 큰 숫자 표시 + 연도 입력·이전해·다음해·올해 버튼 + (상단 고정) 요일 헤더 + 8열(월 표시 1열 + 요일 7열) 연속 날짜 그리드(내부 스크롤)

하단
- 별도 푸터 없음

반응형 대응
- 모바일 대응 필요 여부 : 필요 — 지원함
- 화면 크기별 레이아웃 변화 : 카드 최대 폭 440px, 그 이하 화면에서는 유동적으로 축소. 폰트 크기는 clamp()로 화면 폭에 맞춰 조정

------------------------------------------------

## 6. 세부 동작

**[1년전체 달력 구성 로직 — 반드시 아래 순서로 구현]**

1. 시작일 계산 : 해당 연도 1월 1일이 속한 주의 일요일을 구한다 (1월 1일의 요일 수만큼 날짜를 뒤로 이동)
2. 종료일 계산 : 해당 연도 12월 31일이 속한 주의 토요일을 구한다 (12월 31일의 요일 수만큼 날짜를 앞으로 이동)
3. 시작일부터 종료일까지 하루 단위로 순회하며 날짜 배열을 만든다 (총 일수는 항상 7의 배수이며, 연도에 따라 364~378일 = 52~54행이 나온다. **12행이 아님에 특히 유의**)
4. 위 배열을 7개씩 끊어 한 행(週)씩 그린다 — 이때 월이 바뀌는 지점에서도 배열은 끊기지 않고 그대로 이어진다 (예: 1월 31일 다음 칸에 2월 1일이 같은 흐름으로 바로 이어짐)
5. 각 행마다, 그 행에 포함된 7개 날짜 중 "일(day)이 1이고 연도가 대상 연도와 같은" 날짜가 있는지 확인한다. 있으면 그 월(month) 숫자를 행 맨 왼쪽 열에 표시하고, 없으면 왼쪽 열은 비워둔다.
6. 대상 연도가 아닌 날짜(연초 이전의 전년도 12월 말, 연말 이후의 다음해 1월 초)는 흐리게(dimmed) 표시한다.

❌ 잘못된 구현 예시 : "1월부터 12월까지 순서대로 반복하면서, 매달 첫째 주(7칸)만 그리고 다음 달로 넘어가는" 방식은 각 달의 8일 이후 날짜가 전부 누락되므로 틀린 구현입니다. 반드시 위 1~6번처럼 연초부터 연말까지 하루 단위로 끊김 없이 순회해야 합니다.

## 8. 디자인 및 스타일

- 디자인 톤 : 미니멀 + "잉크·데스크 캘린더" 컨셉 — 상단 스프링 제본 장식, 숫자는 모노스페이스 폰트, 공휴일/주말은 잉크 스탬프를 연상시키는 색상 사용
- 다크/라이트 모드 지원 여부 : 지원 (자동 감지 + 수동 전환)

- 폰트/아이콘 사용 여부 : IBM Plex Mono, IBM Plex Sans KR (Google Fonts) 사용. 별도 아이콘 라이브러리 없이 이모지/유니코드 기호로 버튼 아이콘 대체

## 9. 예외 처리 및 오류 대응

- 입력값이 잘못된 경우 : 연도 입력값이 비어있거나 0 이하이면 직전 값으로 되돌림
- 네트워크 오류 (API 연동 시) : 공휴일 데이터 fetch 실패 시(오프라인 등) try/catch로 조용히 무시 — 달력 자체 기능은 정상 동작하고 공휴일만 표시되지 않음
- 데이터가 없을 경우 (빈 상태 화면) : 공휴일 데이터 범위(2018~2027년) 밖의 연도는 별도 안내 없이 공휴일 표시만 생략됨
- 오류 메시지 표시 방식 : 별도 표시 없음 (콘솔에도 출력하지 않고 무시 — 사용자 경험을 방해하지 않는 것을 우선함)

## 11. 접근성 및 사용성 (선택)

- 키보드 조작 지원 필요 여부 : 버튼·입력·선택 요소는 기본 포커스/키보드 조작 가능. 개별 날짜 셀은 과도한 tab 이동을 피하기 위해 포커스 대상에서 제외
- 스크린 리더 대응 필요 여부 : 주요 컨트롤에 aria-label 적용, 연/월 큰 숫자 표시 영역에 aria-live="polite" 적용. prefers-reduced-motion 환경에서는 애니메이션 비활성화
- 다국어(i18n) 지원 필요 여부 : 미지원 (한국어 전용)

## 12. 코드 작성 규칙

- 단일 HTML 파일이지만 &lt;style&gt;(CSS) / body 마크업(HTML) / &lt;script&gt;(JS) 영역을 명확히 분리해 작성
- 함수를 역할별로 분리 — 날짜 계산(daysInMonth, firstWeekday, dateKey), 렌더링(renderMonth, renderYear), 네비게이션(goToMonth, goToYear), 툴팁(showTip, hideTip, wireHolidayTip) 등
- 각 함수와 주요 블록에 필요한 만큼 설명 포함
- CSS 커스텀 프로퍼티(변수)로 색상 체계를 관리해 다크모드 등 유지보수가 쉬운 구조로 작성
- 네트워크 실패 등 예외 처리 포함
- camelCase 기반의 일관된 네이밍 규칙 준수

------------------------------------------------

## 13. 테스트

- 테스트 방법 : Node.js + jsdom으로 실제 브라우저와 유사한 DOM 환경에서 렌더링·상호작용을 시뮬레이션하여 검증
- 최소 확인한 시나리오 :
  - 날짜 계산 로직의 정확성(요일, 월별 일수, 윤년 처리)
  - 1년전체 연속 달력의 총 행 수, 월 라벨이 정확히 1회씩·순서대로 표시되는지
  - 오늘 날짜 강조, 보기 모드 전환, 다크모드 토글, 연도 이동 시 스크롤 초기화
  - 공휴일 데이터 반영 및 툴팁 표시/숨김(호버, 클릭, 외부 클릭, 보기 전환 시 자동 닫힘)

## 14. 결과물

- 실행 가능한 단일 HTML 파일 (calendar.html) — 더블클릭으로 바로 실행 가능하며, 정적 파일이므로 GitHub Pages 등 별도 서버 없는 호스팅에도 그대로 올릴 수 있음
- 사용된 외부 리소스 및 선택 이유 :
  - Google Fonts (IBM Plex Mono / IBM Plex Sans KR) — 숫자 중심의 "달력·장부" 톤에 맞는 모노스페이스 폰트와, 한글을 자연스럽게 지원하는 산세리프 폰트를 함께 쓰기 위해 선택
  - holidays.hyunbin.page/basic.json (hyunbinseo/holidays-kr) — 별도 API 키 없이 CORS가 허용된 정적 JSON을 그대로 fetch할 수 있어, 서버 없는 단일 HTML 구조에 가장 적합해 선택. 대체공휴일까지 반영된 공식 '월력요항' 기반 데이터이며, 커뮤니티가 매년 갱신
- 앱 사용법 : 파일을 브라우저로 열면 오늘이 포함된 달로 바로 시작함. 상단 탭으로 보기 모드를 바꾸고, 연도/월 입력이나 이동 버튼으로 원하는 시점을 탐색하면 됨
